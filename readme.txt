 空间博弈模拟器

> 一个基于环图死亡-出生更新的空间重复类演化博弈论模拟器。13 种策略人格在圆环网络上竞争、合作、背叛与演化——无需安装，双击即玩。

## 三种模式

| 模式 | 体验 | 适合谁 |
|------|------|--------|
| **感染演变** | 自由沙盒。1–36 人圆环，13 种角色任意拖拽组合，手动触发演化轮次，观察种群兴衰。 | 喜欢做实验、验证猜想的玩家 |
| **经典课堂** | 14 课叙事预测剧场。每课一个社会寓言，先读故事、再选预测、后看演化，最后揭晓「你猜对了吗？」。 | 想从博弈论小白渐进到理解互惠演化的人 |
| **公地悲剧** | 中央资源池博弈。所有人共享一个会枯竭的公共资源，节制还是掠夺？看个体理性如何摧毁集体。 | 理解「共享草场」与「荒漠化」机制的人 |

---

## 核心机制

- **空间囚徒困境**：每个代理只与左右直接邻居互动。双方合作各得 +2；单方背叛，背叛者得 +3、合作者得 -1；双方背叛各得 0。
- **13 种策略人格**：合作者、骗子、傻子、复读机、记仇者、侦探、墙头草、大善人、老好人、跟风狗、和事佬、试探者、混沌。
- **死亡-出生更新**：每轮随机淘汰低适应度个体，空位由左右邻居中得分更高者的策略复制填充——演化不是道德选择，而是数学必然。
- **噪声与宽容**：可选开启 5% 动作误触，演示「没有宽容的互惠」如何在噪声中陷入永恒仇恨螺旋。
- **Web Audio 合成音效**：全部音效由 Web Audio API 实时合成，零外部音频文件。

本项目是**单文件应用**，无构建、无依赖、无需服务器。


## 课堂模式预览

14 课从 4 人微观社会逐步扩展到 36 人大规模网络：

1. **寄生** — 一个骗子混入纯善村庄
2. **前线** — 复仇者夹击逃兵
3. **理想城** — 乌托邦的脆弱性
4. **防火墙** — 互惠策略的群体免疫
5. **冤大头** — 无识别能力的善良注定灭绝
6. **以牙还牙** — 报复让合作变得可信
7. **误伤** — 一次手滑引发的百年血仇
8. **灭火器** — 宽容打破仇恨螺旋
9. **侦探事务所** — 信息就是生存力
10. **变色龙** — 赢存输变的乱世生存
11. **猎手与猎物** — 策略性剥削与识别
12. **瘟疫** — 盲从者如何放大背叛
13. **调解员** — 有限报复 vs 无限报复
14. **终局** — 三方角力的永恒平衡

每课包含：故事背景 → 角色登场 → **50 秒预测倒计时** → 演变剧场 → 结局揭晓（你猜对了吗？）。

## 公地悲剧模式

与经典双边博弈不同，此模式下所有代理共享一个**中央资源池**：

- **节制（C）**：+2 分，不消耗资源
- **掠夺（D）**：+5 分，消耗 4 单位资源
- **荒漠化**：若资源透支，全体进入惩罚轮，掠夺者反亏 -2 分

演示「每个人都理性地多拿一点，集体却走向毁灭」。

## 技术栈

- 单文件 `index.html`（HTML5 + CSS3 + Vanilla JS）
- DOM + CSS Transform 渲染（非 Canvas），原生支持拖拽与动画
- ES6 Class 模块化架构
- localStorage 存档与课堂解锁进度
- Web Audio API 程序化音效
